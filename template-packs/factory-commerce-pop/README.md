# factory-commerce-pop 2.1.0

这是工厂外贸网站/产品口播的可迁移模板包。它只包含可复用设计、组件、音效和策略，不包含客户原片、文案、字幕、商品图、Logo、交付视频或转录缓存。

## 编辑规则（人读）

以下规则由剪辑者 / Agent 执行，脚本不解析（2026-09-11 自 `pack.json` 的 `*Policy` 迁出；`pack.json` 只保留脚本真读的字段）。

- A-roll：去掉拍摄指令和片头片尾废片；跨 take 接句时保留完整语义并删除边界重复词，允许无缝续句而不把前一 take 判为失败；所有切点都要看电影条和波形；字幕逐条对照词级缓存复核，不只看报告时码；清除误录的口令、点击和转场杂音。
- 输出：源片为 59.97fps 时母版保持 `60000/1001`，不降成 30fps；平台版本从高质量母版派生。
- 字幕：手机端单行，默认 64px（`pack.json` 的 `caption.fontSize` 是唯一来源，主题 CSS 不再另写字号），通常每条 3–4 个词；严格水平居中；重点短语为黄字黑描边，不加额外方框；下一句不得抢在上一句说完前出现。
- 顶部纸条：只显示域名或核心短语，不加 `MARKETPLACE` 等冗余标签。
- 开头否定语义：允许在被否定的平台 Logo 上叠加红色打叉贴纸。
- 列表悬念：说“4 sites”等列表核心时用 Web/地球/浏览器贴纸，保持 3.5–5 秒，不提前公开全部条目。
- 域名纸条可见期间隐藏重复的域名字幕；手机端主信息卡默认 3:2 大面积高反差；动效入场短促 pop / punch，不做纯闪烁；每个分支必须有语义提示音。
- B-roll 覆盖不超过 25%（脚本校验），默认悬浮框（floating-frame），证据优先，不预览全部列表条目。
- 分支内容：每个网站/文章分支都必须有对应大品类图和明确但短促的提示音。
- CTA：收藏/关注仅保留主词、图标和一次点击状态，不加顶部说明条。
- 音频：不强制 BGM；语义音效全片不超过 12 处；默认 5.5 秒前不加额外 SFX（开头音效需明确批准）；核心点用 `pop + ding`，每个分支用统一 `pop hit`；联系型 CTA 配与动作同步的打字 / 电话 / 提示音且人声优先；先做局部增益包络或压缩再做整条响度正规化；最终目标约 `-13 LUFS / -1.2 dBTP`。
- 调色美颜：先逐拍摄片段匹配曝光，再运行 `factory-neutral-skin-v1` 非生成式终调，统一为明亮中性肤色；边缘保护磨皮后轻回锐，不重建五官。每条真片必须保留至少两组同帧前后对照。

## 音效来源

`assets/sfx/` 下 4 个 WAV（`pop-soft` / `final-ding` / `click-confirm` / `follow-confirm`）于 2026-09-11 由 `scripts/generate-commerce-pop-sfx.mjs` 以确定性 PCM 合成重新生成：客户 2026-09-05 快照不含二进制音效，原始文件已不可追溯。全部为短促原创波形，不采样、不含任何第三方音频；重跑脚本即可得到字节一致的文件。

## 使用

新 job 选择：

```text
templatePack: factory-commerce-pop
profile: factory-acquisition
```

模板会自动把通用音效和 Web 悬念贴纸复制进 job。产品图片、平台 Logo 和实际域名仍应按每条视频语义提供，避免把客户内容固化进模板。

跨电脑迁移随仓库发布：目标机 `npm run update` 检出最新 `v*` tag 即可，不再提供独立 ZIP / 便携安装器（2026-09-11 起）。
