# factory-rapid-proof

从公司自有高流量参考视频抽象出的可复用模板包。只保留字幕、版式、动效和剪辑节奏规则，不包含参考视频中的人物、台词、房屋、Logo 或其他专有媒体资产。

## 推荐映射

- `hook-stack-banner`：前 0.5–1.5 秒展示“注意力词 / 品类 / 核心量化卖点”。
- `iris-reveal`：只用于开场或明确章节切换，建议 6–18 帧完成。
- `keyword-burst`：评论、私信或询盘关键词出现时，跟随重读音节逐字弹入。
- 字幕：2–5 词一组，默认黄色，重点短语可切白色，黑色重描边且无底框。

## 编辑规则（人读）

以下规则由剪辑者 / Agent 执行，脚本不解析（2026-09-11 自 `pack.json` 的 `*Policy` 迁出；`pack.json` 只保留脚本真读的字段）。

- 开场前 0.5 秒放分层价值卡，再用 6–18 帧的黑色圆形揭示进入正片。
- 证据节奏：说话人 / 模型演示 / 全屏工厂实景交替；每段证据 1.2–3.5 秒，语义硬切，不做过渡动画。
- 人脸优先；每个切点都要有语义 EDL + 电影条 + 波形审核。
- 字幕每条 2–5 词，默认黄色，重点短语切白色，黑色重描边、无底框；按语义短语硬刷新，跟随词级缓存对口型。
- 动效：钩子用分层卡片 punch 入场；关键词 CTA 逐字弹入并按重音回落；不做纯闪烁；所有动效必须有语义触发。
- B-roll 覆盖不超过 25%（脚本校验），默认全屏，证据优先，单段 1.2–3.5 秒。

原参考帧仅保存在本机 `themes/rapid-proof/reference/`，该目录不会进入公开仓库。
