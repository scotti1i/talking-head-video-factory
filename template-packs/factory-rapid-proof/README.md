# factory-rapid-proof

从公司自有高流量参考视频抽象出的可复用模板包。只保留字幕、版式、动效和剪辑节奏规则，不包含参考视频中的人物、台词、房屋、Logo 或其他专有媒体资产。

## 推荐映射

- `hook-stack-banner`：前 0.5–1.5 秒展示“注意力词 / 品类 / 核心量化卖点”。
- `iris-reveal`：只用于开场或明确章节切换，建议 6–18 帧完成。
- `keyword-burst`：评论、私信或询盘关键词出现时，跟随重读音节逐字弹入。
- 字幕：2–5 词一组，默认黄色，重点短语可切白色，黑色重描边且无底框。

原参考帧仅保存在本机 `themes/rapid-proof/reference/`，该目录不会进入公开仓库。
