# factory-b2b-leadgen 1.0.1

这是将多轮工厂外贸口播审片要求固化后的独立模板包。它面向 TikTok、Instagram Reels、抖音等手机端 B2B 获客视频，适用于中文、英文、西班牙语及其他有可靠书面文稿的口播。

## 一键预设

本包必须按三条正交轴共同使用：

```text
profile: factory-acquisition
fineCutPreset: social-fast
templatePack: factory-b2b-leadgen
```

- `profile` 负责文稿保真、A-roll 连贯性、美颜和交付门禁。
- `fineCutPreset` 负责 1.1 倍速建议、黄金三秒、气口与段首口令处理。
- `templatePack` 负责字幕、色卡、B-roll、Zoom、音效、封面和 CTA 包装。

模板不会用静音检测自动决定切点，也不会因为追求快节奏而删掉正确单词。

## 编辑规则（人读）

以下规则由剪辑者 / Agent 执行并按 `docs/qa-checklist.md` 验收，脚本不解析（2026-09-11 自 `pack.json` 的 `*Policy` / `requiredWorkflow` / `workflow-contract.json` 迁出；`pack.json` 只保留脚本真读的字段：主题、字幕排版、组件、资产、B-roll 覆盖上限）。

- 开头有效首音默认在 0.08 秒内进入；交付首帧还必须同时出现对应嘴型和已进入口播状态的人物表情，吸气、张口/举手准备即使有小波形也删除。
- 逐 take 删除“开始”等拍摄口令；尾部删除“念完了/完了/拍完了/done/finished”等不属于文稿的收工元话语。
- 正确词语、句尾和嘴型闭合必须完整；每个切点审核文稿、词级缓存、波形、电影条和人物状态。
- 字幕默认 66px、手机安全区居中、普通白字、重点黄字；保留原文大小写，不强制全大写。
- 有声音必须有完整对应字幕，无声音不留字幕；不得漏词、抢跑、延迟或把两句话合并为一条。
- B-roll 优先使用真实工厂、产品、店铺和联系证据；去除素材原声，至少 1080p，字幕 Y 轴与 A-roll 一致。
- 文稿连续列举产品品类时，使用授权或用户自带的实物图片做手机端大卡片顺序切换，并逐项对齐当前口播；不把多张小图一次性堆在屏幕上。
- 相邻 B-roll 直接衔接，不在中间闪回不足 0.5 秒的 A-roll；空镜不能掩盖没剪掉的静音。
- 一条口播通常只安排 3–4 次 Zoom：8–9 帧推至 130%，以人脸为中心保持到语句结束，再用 8–9 帧回落；转场后至少 2 秒再 Zoom。
- 开头、转场、空镜、色卡、Zoom 和 CTA 按语义配音效；2 秒内事件密集时只保留一个优先音效。色卡使用圆润、力量较弱但清晰的声音，禁止重拍击打感。
- BGM 按需求启用；推荐 105–115 BPM 的轻快 Epic、Funk 或 Trending，通常比人声低 12–15 dB。
- A-roll 使用 `factory-neutral-skin-v1`：先逐 take 匹配曝光，再做明亮中性肤色、轻磨皮和回锐；默认不改脸型。
- 联系型收尾使用真实产品 B-roll 与邮件、电话或打字贴纸组，并配对应音效；比正文强调更明显，但不能压人声。
- 封面人物端正居中，红色钩子位于头顶上方一点，不压脸；优先放在不透明黄色横条上并减少黑色阴影。
- 字幕每条 2–4 个词，A-roll 与 B-roll 字幕同一 Y 基线；句尾句号、逗号去掉，问号 / 感叹号按语义保留；新从句新字幕，不为凑宽度合并两句。
- A-roll 倾向 1.1 倍速（口齿受影响时不变速）；逐 take 做局部增益包络或压缩后再做整条响度正规化；开头与相邻口播窗口响度差不超过 1 dB。
- B-roll 覆盖不超过 25%（脚本校验）；默认语义全屏或画中画；来源优先级：用户自带真实证据 > 授权 1080p 真实素材 > 仅在无真实素材时用生成的解释画面；工作副本统一 mp4 / SDR BT.709 / 变体帧率，30→60fps 用帧混合；进入点与有效起声同步或该 take 连续口播 2 秒后；转场短促、只配一个中等音效。
- 贴纸按手机优先放大到桌面版式的 1.5–2 倍；平台 Logo 跟随说话人手势顺序与位置、同步退出、圆角无黑边；关键主张配真实产品 / 工厂 / 店铺 / 联系证据；同一大色卡不跨产品重复。
- 音效电平通常低于人声 10–16 dB，按耳朵微调；开头必配音效；Zoom 只在附近无其他提示时配极轻空气声。
- 混音目标 −13 LUFS 综合 / −1.5 dBTP 峰值。
- 输出 mp4、48 kHz AAC、SDR BT.709 yuv420p；帧率由变体决定（默认 60fps，不得暗降 30fps），并明确记录 60000/1001 与 60/1 的差别；先出母版再派生平台版本。
- 交付物：最终 MP4（全解码抽帧 + 音频 + 色彩 QA）、干净 A-roll、SRT、EDL、反馈记录与 QA 记录。

`pack.json` 是唯一机器可读文件；上面的规则只写在这里和 `docs/qa-checklist.md`。

## 新项目用法

```powershell
npm run intake -- --dry-run --slug <项目名> --source <素材目录> --language <语言代码> --template-pack factory-b2b-leadgen --fine-cut social-fast
```

确认后去掉 `--dry-run` 正式导入。原片仍只读复制，不会写回素材目录。

## 跨电脑安装

本模板包随仓库一起发布：目标机在 WSL 仓库里 `npm run update`（检出最新 `v*` tag）即可获得，不再提供独立 ZIP / 便携安装器（2026-09-11 起，发布 = 打 tag）。仓库不包含客户原片、文稿、转录、成片、API Key、第三方 BGM 或第三方原始音效库。
