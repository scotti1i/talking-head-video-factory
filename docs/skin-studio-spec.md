# 皮肤 `studio` · Design Spec（一页）

> 2026-09-07 Scott：「换一套模板，至少视觉风格换、背景效果换；增加口播出镜；只有 A-roll 的时候别把我剪成竖屏，我本来就是横屏素材。」全权授权，按无人值守规则先落 spec 再动手。

## 一句话

**人是画面，信息是叠层。** 不再有黑板舞台；默认态是 16:9 全画幅正脸（Pocket 原片轻调色），信息以「右侧浮动栏」和「全屏插页」两种形式叠上来，插页几秒后回到人。

## 对标

- Apple Keynote 现场记录 / Apple「Behind the Mac」访谈段：人占画面，字幕层克制，一种强调色。
- OpenRouter / Linear 的深色控制台：海军蓝底、发丝线、无渐变高光。
- 不对标：小Lin 黑板（已做过两版）、任何网点 / 等高线 / 粒子背景。

## 色板

| 用途 | 值 |
|---|---|
| 插页 / 浮动栏底 | `#0B1630` 深海军蓝（Scott：主色偏海军蓝，绿色廉价、金色已用过） |
| 浮动栏玻璃 | `rgba(11,22,48,.78)` + `backdrop-filter: blur(24px)`，1px `rgba(255,255,255,.14)` 发丝线 |
| 文字 | `#FFFFFF` 主 / `rgba(255,255,255,.62)` 次 |
| 唯一强调色 | `#7FB2FF` 冰蓝（字幕关键词、当前项、判定徽章）|
| 警示 | `#FF7A70` |
| 背景（非全画幅时） | 原片本身高斯模糊 40px + 压暗 45% + 海军蓝 12% 叠色；不用任何图片背景板 |

## 字体

苹方（PingFang SC）全场；数字 SF Pro Display；标题 800 字重、字距 -0.03em；正文 600。无衬线，无装饰字。

## 人物三态（替代竖卡）

| 形态 | 画面 | 内容区 | 适用 |
|---|---|---|---|
| `full` | 16:9 原片铺满 1920×1080 | 右带 / 下三分之一（只放点缀、字幕关键词、贴脸胶囊） | 默认态，纯口播段落 |
| `wide` | 16:9 横卡 1200×675，居左（x 60，y 100），圆角 28，发丝线 + 深柔影 | 右栏 x 1300–1866（宽 566） | 提醒卡、点缀、单列阶梯、短标签 |
| `pip` | 16:9 小卡 466×262，左上角（x 54，y 54） | 主区 x 60–1860、y 340–900 | 排行榜、关系图、公式、汇流、时间线、对比、B-roll 面板 |

换位曲线沿用 SharedElementMorph（35f）。`full → wide` 是画面整体缩进左卡，`wide → pip` 是卡飞到左上角，观众看到的是同一张画面在变大变小，不是切镜头。

## 版式规则

1. 全片 ≥ 55% 时长人物为 `full` 或 `wide`（人多出镜是硬指标，编译器 `auditStructure` 报占比）。
2. 插页（`pip` 态 + 大板子）单段 ≤ 12 秒，之后必须回 `full`/`wide` ≥ 4 秒。
3. 浮动栏内元素上限 3 个；插页内元素遵守既有几何 / 覆盖率门禁。
4. 字幕沿用 56px 白字硬阴影（Scott 定过不改），关键词改冰蓝。
5. B-roll：`full` 通栏保留；`panel` 只在 `pip` 态下用，落主区。

## 三个禁止项

1. 禁止竖版人像卡：任何形态下人物画面都是 16:9。
2. 禁止黑板 / 网点 / 等高线 / 粒子 / 光斑背景；背景只能是原片模糊或海军蓝实底。
3. 禁止渐变高光、发光、拟物；强调色只有冰蓝一种，不出现青柠 / 金 / 紫 / 酒红实底。

## 验收

- 三张风格样张（`full` 纯口播 / `wide` + 提醒卡 / `pip` + 排行榜插页）与 Apple Keynote 现场记录截图并排，是同一档次。
- 用本次三游戏片 A-roll 重出 60 秒样片，独立审片十条通过，人物出镜占比 ≥ 55%。
- 反向检查：把样张缩到手机大小，正脸和关键词一眼能读，板子文字不需要读也能懂在讲什么。
