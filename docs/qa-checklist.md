# QA Checklist

## 结构检查

- [ ] `index.html` 有顶层 `data-composition-id="main"`
- [ ] video 是 `muted playsinline`
- [ ] audio 是单独 `<audio>`
- [ ] 所有字幕 / 章节 / 解释层都有 `data-start`
- [ ] 所有字幕 / 章节 / 解释层都有 `data-duration`
- [ ] 所有 timed clip 都有唯一合理的 `data-track-index`
- [ ] timeline 同步注册：`window.__timelines["main"]`

## 剪辑切点

- [ ] 每个 EDL 保留段都有语义理由。
- [ ] 每个切点都生成电影条 + 波形。
- [ ] 逐张检查嘴型、动作、音节截断、重复语义和过紧节奏。
- [ ] `factory-acquisition` / `social-fast` 第 0 帧封面后，首个有效音节和每个新 take 的首个有效音节均在 0.08 秒内进入；除明确留白和转场 0.1–0.3 秒缓冲外，没有可感知气口。
- [ ] 首帧同时通过有效首音、对应嘴型和人物口播状态三项检查；吸气、张口准备、举手准备、找镜头等画面即使有小波形也已经删除。
- [ ] 每个 take 段首都单独听审；拍摄者“开始/Action/Go”、异语言提示词、数拍、碰麦及演员未进入状态的准备画面均已排除，不能仅依赖项目语种 ASR。
- [ ] 每个 take 尾部都检查书面文稿之外的收工元话语；“念完了/完了/拍完了/done/finished”等只服务拍摄流程的声音与画面已在最终尾词闭口保护后删除。
- [ ] 每个保留段尾词都同时检查词级时码、波形衰减和嘴型闭合，并在完整发音后留 0.08–0.25 秒保护量；字幕包含该词但声音被截断仍判失败。
- [ ] 已运行 `npm run dialogue:qa -- --job jobs/<slug>`；`qa/dialogue-continuity-report.json` 必须通过段首、尾词、局部响度和 B-roll 边界门禁。
- [ ] 只有看完证据后才存在 `qa/cuts/approval.json`。

## 字幕检查

- [ ] 字幕校准先通篇读完整条转写，明确主题、术语体系、口播语境，再做局部修字。
- [ ] 不凭单个 ASR 片段或常识改核心术语；用户确认过的词优先于模型猜测。
- [ ] 平台名、模型名、产品绰号、行业词必须全片统一，不能一处一个写法。
- [ ] 字幕不是运行时 DOM mutation
- [ ] 字幕已从 JSON 生成静态 clip
- [ ] 字幕不长期压嘴
- [ ] 字幕字号在手机上足够大
- [ ] 英文产品名没有被切得太碎
- [ ] 解释层出现时，字幕保留并按需要让位
- [ ] A-roll 每次重剪后都重新映射字幕；最终 MP4 逐段检查起声、尾音、漏句和抢词，不能只检查时间轴 JSON。
- [ ] 人声覆盖是硬门禁：每段有效口播都有对应字幕或经声明的等价屏幕文字；无人声区不残留字幕，字幕不能跨过可感知静音继续显示。
- [ ] 字幕词面正确性也是硬门禁：`caption-voice.json` 每段 `expectedText` 必须逐词覆盖实际口播，顺序一致；漏词、多词、错序均不合格，不能以“有字幕覆盖”为替代。
- [ ] A-roll、B-roll 和画中画状态的主字幕使用同一条 Y 基线；不得因底层画面类型切换而上下跳动。
- [ ] 运行 `npm run captions:voice-qa -- --job jobs/<slug>`，并复核 `qa/caption-voice-report.json`；声区由波形、转录语义和人物状态共同批准，不由静音检测自动决定；报告必须同时通过时间覆盖和 `expectedText` 逐词核对。
- [ ] `factory-commerce-pop` 竖屏字幕默认 64px；普通字幕、全屏证明素材字幕与高亮词都继承同一字号、水平中心和描边规则，不允许 B-roll 字幕回退到旧字号。
- [ ] 工厂获客 A-roll 运行注册的非生成式美颜终调后，至少抽查两个不同时间点的同帧前后对照：人物需明显提亮、肤色不得暗黄，皮肤纹理和五官仍真实，发丝、眼睛和嘴型不得因磨皮产生闪烁或重建痕迹。

## 解释层检查

- [ ] 不挡眼睛
- [ ] 不长时间挡嘴
- [ ] 半透明，不像整页 PPT
- [ ] 信息少而准
- [ ] 每个解释层都在最终 MP4 抽帧里出现
- [ ] 手机端主信息卡避免细长横条；需要承载标题、图形和附属字时优先接近 3:2，并以手机预览确认实际画面占比和可读性。
- [ ] 3:2 主信息卡默认占竖屏宽度约 60%–72%；正文与背景必须使用硬反差色，正文对比度至少达到 WCAG AA 4.5:1，不允许白底浅黄字或其他低反差组合。

## B-roll 检查

- [ ] 每段都有明确 `intent` 与 `reason`。
- [ ] 默认保留说话人小窗。
- [ ] 前 3 秒默认不用、单段 ≤10 秒、总占比 ≤25%、相互不重叠。
- [ ] 真实产品界面使用真实截图或录屏，不用伪造 UI。
- [ ] 相邻语义 B-roll 不夹入少于 0.5 秒的 A-roll 闪回；优先直接衔接，确需回人物时保留至少 0.5 秒且画面有完整表情或语义动作。
- [ ] B-roll 只在 take 有效起声时同步进入，或在该 take 连续口播至少 2 秒后进入；不得遮住未剪掉的段首气口、口令或准备画面。
- [ ] B-roll 退出后 1 秒内若存在 A-roll take 切点，必须延长跨过切点并保留约 0.3 秒后摇，或至少提前 2 秒退出；1 秒内不得连续出现上一段、空镜、下一段三次切换。
- [ ] 外部图片/视频的来源、许可和 SHA-256 已记录；所有 B-roll 工作副本无音轨，且每段真实素材与当下口播语义直接对应。
- [ ] 文稿连续列举太阳能、家具、礼品、玩具等产品品类时，已优先使用授权或用户自带实物图片做手机端大卡片顺序切换；卡片与当前读到的品类对应，不把多张无关小图同时堆满画面。
- [ ] 入时间线的是派生工作副本而非原始 MOV：MP4 / 60fps / yuv420p / TV range / Rec.709 / ≤1 秒 GOP；30fps 升帧使用帧混合或运动插值。
- [ ] HLG / BT.2020 已 tone-map；三段 B-roll 的曝光、白平衡和饱和度已用审色抽帧做相邻镜头一致性检查。

## 镜头缩放与动效音效

- [ ] 段落级人脸 Zoom 以脸部为中心，从 100% 在 8–9 帧内推到目标比例（最高 130%），保持至当前语句结束，再以相同帧数回到 100%；不得做成一闪即回的普通转场。
- [ ] 多段 Zoom 的起止点服从语句结构，不能截断表情或与相邻转场/B-roll 写入同一画面变换区间。
- [ ] 未经用户特别指定，工厂商业引流口播全片只使用约 3–4 次 Zoom；不能因每个贴纸或重点词重复触发。每次放大后脸部中轴需落在目标视觉中心附近。
- [ ] 转场、色卡、空镜和重点动效使用清晰可辨、偏提示型的音效；避免可爱软弱或过强刺耳，同时保证人声优先、峰值不过载且连续听感舒适。
- [ ] 联系型 CTA 的邮件/电话画面、联系贴纸与键盘/提示铃声时间对齐，形成完整动作组，而不是孤立叠加声音。
- [ ] 收尾视觉按当条产品语义变化：优先使用至少 1080p、来源许可与哈希齐全的真实产品/工厂 B-roll，再叠加简洁高对比 CTA；不跨项目固定复用同一种大色卡。
- [ ] 对白内部响度已按 0.1–0.2 秒窗口复核；相邻有效人声窗口修正后跳变不超过 4dB，先做局部增益包络/压缩，再做整条 LUFS 正规化。
- [ ] `factory-acquisition` 的联系/询价/私信/写信/电话类收尾默认包含真实联系动作或语义贴纸、明确联系卡和动作同步音效；中段贴纸/色卡提示音明显弱于收尾强提醒，连续听感不压迫。
- [ ] A-roll 提亮、自然磨皮和轻度脸型优化已有同帧前后对照；肤色、五官和边缘无明显失真，且原片未被覆盖。
- [ ] 独立封面文字能在手机端读清，人物状态端正；如要求挂首帧，最终 MP4 的第 0 帧与 `cover/cover.png` 一致。

## 抖音安全区

- [ ] 上方不贴太近
- [ ] 下方不被底部 UI / 字幕区吃掉
- [ ] 右侧留出互动栏空间
- [ ] 关键字不放在最右侧
- [ ] 人脸是主体，包装是辅助

## 最终文件检查

用 `ffprobe` 或 `npm run qa` 确认：

- [ ] 1080x1920
- [ ] 60fps
- [ ] 有音轨
- [ ] 时长正确
- [ ] 码率接近 24Mbps
- [ ] 最终 MP4 可以正常播放

## 多版本检查

- [ ] 抖音竖屏：1080x1920，字幕不压嘴，右侧互动栏安全。
- [ ] YouTube 横屏：1920x1080，口播主体保留，信息层不变 PPT。
- [ ] YouTube Shorts：从母版或高码率竖屏派生，不从平台下载件二压。
- [ ] 每个 variant 都单独跑 `lint / validate / inspect`。
- [ ] 每个 variant 都单独抽最终 MP4 帧。

## 抽帧检查

至少抽：

- [ ] 开头 0-10s
- [ ] 普通字幕点
- [ ] 章节出现点
- [ ] 每个解释层出现点
- [ ] 结尾 CTA

抽帧文件位置：

```text
jobs/<slug>/qa/final-frames/
```
