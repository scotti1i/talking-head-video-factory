## 落进规则的

- 手册 §5-7：网页录屏只留实录区，裁掉页面大标题 / 品牌栏 / 营销文案（整版精修页 = 广告页）。
- 同一份分镜 v8 审片通过、v9 打回三处未改动的地方：独立审片有随机性，「通过」只说明这一位没看到，不说明没问题；每版都要自己再看抽帧。
- 相邻舞台场景（板子 / 面板）间隔 ≥0.6s：模板入场提前 0.3s、退场拖后 0.3s，间隔小于这个数一定交叠；贴脸胶囊在人物回全画幅 ≥0.5s 后才出现。该进编译器几何门禁（目前只查换位后 0.5s）——审片人只把 <1.5s 入场算过程帧，退场叠影它不一定报。

## 未达标

- 人物出镜（full + wide）30%，手册目标 ≥40%。原因：证据密度高（25 场里 B-roll + 面板占 24%+），且 studio 的 pip 态算「出镜不足」。下一条片在分镜阶段就控制面板总时长，或让 wide 态多承担提醒 / 点缀。
