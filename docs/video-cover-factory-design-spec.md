# GPT Image Cover Factory · Design Spec

状态：3:4 母版与 `neutral-daylight` 肤色已批准  
首个系列：`50天50个AI应用落地挑战`

## 目标

最终封面由 GPT Image 2 直接生成，包含人物、美颜、背景、文字和排版。任何本地脚本都不得拼接成品。观众不看标题也能凭颜色、Day 系统和视觉语言识别系列；人物必须能一眼认出是本期视频里的 Scott。

## 最短工作流

1. 从本期原视频抽取 12 帧，选 3 张真实身份参考：正脸、三分之二侧脸、另一表情。
2. 用 3 张参考脸直接生成一张 `3:4` 系列母版。
3. Scott 验收脸、美颜、文案和风格；批准后冻结为系列锚点。
4. 后续所有期数都使用“本期 3 张真实脸 + 已批准母版”直接生成。
5. 每个画幅单独生成原生构图，不从一张图机械裁切。

## GPT Image 2 的职责

- 生成完整的成品封面；
- 在保持本人身份的前提下做商业人像美颜；
- 把同一视觉语言重排为 `3:4`、`4:3`、横屏 `16:9`；
- 依据母版锚点保持 50 期的系列感。

## 本地程序的职责边界

只允许：视频抽帧、清晰度/单脸/角度评分、候选联系表、参考帧复制、输入哈希和 QA 记录。

禁止：HTML/CSS、Pillow、canvas、SVG、ImageMagick、ffmpeg overlay 或任何形式的成品拼图；也禁止在生成后本地补字、贴脸、磨皮或改版。

## `50×50` 新系列方向

定位：一场连续 50 天、每天交付一个真实 AI 应用的公开实验。它不是课程海报，也不是传统黑黄“知识博主”封面。

- 视觉情绪：高能、当代、专业、带真人创作者气质；像一场有连续编号的产品发布运动。
- 主色：高饱和群青 / 电光紫渐变。
- 信号色：热珊瑚红，只承担 Day 编号和一个动作焦点。
- 中性色：深墨黑与高亮白。
- 主识别物：超大 `DAY 01`、固定系列名、一道斜向动势或光带、近景真人肖像。
- 人物：画面最大视觉锚点，靠右或居中偏右；真实五官，高级商业人像光，不做廉价赛博人像。
- 标题：一句结果导向的短句，不堆关键词。
- 质感：电影棚拍肖像 × 新产品发布；干净、锐利、手机小图仍有冲击力。

首张母版只允许三组可见文字：

1. `50天50个AI应用`
2. `DAY 01`
3. `一句话交付品牌物料`

不得自动添加英文副标题、按钮、logo、平台名、假 UI 或解释性小字。

## 人脸与美颜

默认合同：`identity-first-neutral`。不再用“美颜百分比”描述，因为模型容易把百分比错误映射成瘦脸或磨皮。

视频帧只锁定脸型、五官、发型、年龄和辨识度；其中的偏红/偏紫室内色温、临时痘印、疲态和手机高光不作为身份特征。允许中和偏色，降低临时泛红、明显瑕疵和油光的对比，保留毛孔、淡胡茬、真实肤质与色阶。

必须锁定：脸型宽度、头型、发际线、发色、眼形与眼距、鼻子、嘴唇、痣、天然不对称、年龄、族裔和整体辨识度。

禁止：下颌塑形、光影瘦脸、削弱脸颊饱满度、拉长下巴、塑料皮、放大眼睛、改鼻改唇、换发型、换年龄、换族裔、生成“像 Scott 的另一个人”。

首张母版批准前，先生成三张只改变皮肤与光线的校准版本：中性自然、健康暖调、柔光棚拍。脸型、表情、版式和文字必须相同；Scott 选择后再冻结进系列母版。

已选结果：第一张 `neutral-daylight`。母版固定在 `skills/video-cover-factory/assets/series/50-days-50-ai-apps/series-master-3x4.png`，后续期数与所有画幅必须携带它作为风格和肤色锚点。

## 画幅

| 画幅 | 用途 | 原生重排原则 |
|---|---|---|
| `3:4` | 抖音主页 | 系列母版；脸和 `DAY 01` 都必须在中央安全区 |
| `4:3` | 横屏渠道 | 左文案、右人物，保留同一色带和编号语言 |
| `16:9` | YouTube 横屏标准封面 | 左文案、右人物，原生横屏重排；不是把 3:4 左右补边 |

本系列不默认生成 `9:16`。用户说“YouTube 横屏”时，一律解释为标准 `16:9`。

## 三个禁止项

1. 禁止本地拼图冒充生图。
2. 禁止美颜改变 Scott 的身份结构。
3. 禁止没有母版参考就靠提示词连续生成 50 期。

## 验收门

- 第一眼认出本人，不是相似脸。
- 美颜明显改善镜头状态，但仍看得到真实皮肤纹理。
- 文字逐字正确，Day 无误，无模型自作主张的小字。
- 缩到手机列表尺寸仍能读出 Day 和本期结论。
- 四种画幅是同一 campaign，不是四套临时设计。
- 后续期数始终携带批准母版作为风格锚点。
