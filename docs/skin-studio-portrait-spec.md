# 皮肤 `studio-portrait` · Design Spec（一页）

> 2026-09-07 Scott：「主要做我的口播，其他动画各种都是辅助，字体还是 xiaolin 的模板，注意力在我身上，做竖屏。」压缩按注意力，皮肤 studio，闭环授权。

## 一句话

**人永远铺满竖屏，信息只在脸下面出现。** 没有卡片化的人物、没有换位；只有两种镜头：原片（full）和推近（focus）。

## 画布与镜头

| 形态 | 画面 | 内容区 | 适用 |
|---|---|---|---|
| `full` | 1080×1920 原片铺满 | 脸两侧贴脸胶囊（左侧右缘 x≤360，右侧左缘 x≥840，y 500–610） | 默认态，纯口播 |
| `focus` | 原片放大 1.1、上移 270：整个头留在画面里（2026-09-08 Scott：头别太靠上），下巴以下留白 | 下区 x 60–900、y 990–1300 | 提醒卡、阶梯、对比、排行 |

两态之间是同一画面的推近 / 拉远（35f 曲线），不是切镜头。右侧 x>930、y 1000–1700 是抖音图标区，任何元素不进；底部 y>1450 是字幕与抖音文案区。

## 色板与材质

沿用 `studio`：海军蓝 `#0B1630` 玻璃面 `rgba(11,22,48,.78)` + 24px 模糊 + 1px 发丝线；文字白 / 62% 白；唯一强调色冰蓝 `#7FB2FF`；警示 `#FF7A70`。背景就是原片本身（人铺满，没有背景板）。

## 字体与字幕

苹方 800 标题、600 正文；字幕 52px 白字硬阴影，居中，底部 470px 以上（抖音 UI 之上），关键词冰蓝。

## 版式规则

1. 人物出镜 = 100%（两态都是人）；`focus` 单段 ≤ 12s，之后回 `full` ≥ 4s。
2. 下区元素上限：提醒卡 3 条、阶梯 4 步、对比 2 卡；文字 ≤ 12 字一行。
3. 贴脸胶囊只在 `full` 态出现，且在人物回 `full` ≥ 0.5s 后；`focus` 态脸更大，两侧没有胶囊位。
4. 相邻舞台场景间隔 ≥ 0.6s（手册 §5-9）。
5. 不用通栏 B-roll；证据类画面只做下区小图。

## 三个禁止项

1. 禁止把人物缩成任何卡片或角标；两态都是全画幅。
2. 禁止元素进入脸区（`full`：x 390–810、y 230–1230；`focus`：x 200–880、y 0–970），编译器几何门禁按此查。
3. 禁止渐变高光、发光、拟物；不出现横屏版的黑板 / 光斑 / 网点。

## 验收

- 三张风格样张：`full` + 贴脸胶囊 / `focus` + 提醒卡 / `focus` + 阶梯，缩到手机尺寸第一眼是「他在说话」。
- 独立审片十条通过 + 一条「注意力在人」：任一帧里叠层面积 ≤ 画面 25%。
