# Shotcraft 直接移植设计规格

状态：已确认并进入生产。Scott 已在本会话确认原版 `AiflPromo` 动态基准，并要求直接移植，不接受截图临摹或凭理解重做。

## 动态对标

唯一动态基准是 Video Shotcraft 随库提供的 `Ink Press / AiflPromo` 原始 Remotion 成片。当前预览为原代码零改动渲染：

- 成片：`artifacts/shotcraft-direct-port/original-aifl-promo.mp4`
- 六帧总览：`artifacts/shotcraft-direct-port/contact-sheet.png`
- 上游版本：Video Shotcraft gallery revision `bdd94be16d60fa8f`
- 许可证：Apache-2.0；移植时保留 LICENSE、来源与修改说明

## 移植范围

上游整组源码已作为只读基线移植；首批开放三个可替换真实内容的生产接口，不拆成自制卡片：

1. `PaperTitleCard`：段落呼吸字卡及其逐词节奏。
2. `SceneDetail → row-embed`：9 帧错峰、12 帧飞入、16° X 轴翻转、压弹与琥珀缝线。
3. `ScenePapers → list-stack-press`：12 帧错峰、22 帧落位、交替倾角、堆叠压弹、扫光与计数。

`SceneOpen`、`SceneFlyIn`、`SceneWbr`、`SceneOutroLive` 等其余六段已保留源码和原版预览，但在内容参数接口与真实素材验收完成前，不暴露给 Planner。

第一条样片只替换真实内容、中文文案、目标截图与人物构图；保留原缓动、时长比例、hold、镜头路径和音效结构。

## 色板与字体

- 色板不由工厂擅自指定。第一版保留上游纸墨琥珀：页面纸底 `#faf7f2`、墨字、琥珀单点强调。
- 如果 Scott 不接受这套皮肤，只更换集中式 token，不改镜头运动；新色板另出对照帧后再确认。
- 英文原片的衬线标题保留其度量关系；中文生产替换为有完整中文字符集的宋体/现代黑体组合，先做真实文案排版帧，不允许出现占位英文。

## 人物与口播的接法

- Shotcraft 镜头作为 Remotion 原生全屏 B-roll 或对侧信息面板渲染，不翻译成 HyperFrames HTML 卡片。
- A-roll 继续由现有工厂负责；人物满幅、缩位、角标切换只在语义边界发生。
- 人物在场先测人脸框；任何文字、卡片及其背景不得侵入人脸安全区。
- 配方片段保留原 SFX，并以独立音轨接入最终时间线；为保证并行渲染可随机寻帧，配方媒体统一规范为最多 1 秒关键帧间隔。

## 三个禁止项

1. 禁止根据截图、卡名或说明文档重新手写“神似版”。
2. 禁止逐 job 擅自改配色、添加英文标签、金句、装饰线或新卡片。
3. 禁止在没有真实截图/数据/来源时用假 UI 冒充证据；上下文不足则回退人物画面，不编造。

## 验收

- 源码保真：每个移植镜头有上游 TSX、来源路径、哈希和修改清单；vendor 哈希与 `PageCam`、坐标、时间点、缓动、相机参数的自动断言必须通过。
- 动态保真：渲染后固定抽取入场、动作、稳定、退场四阶段电影条复核；批准绑定当前媒体与电影条哈希，任何变化都失效。
- 确定性：任何依赖全局帧而在随机寻帧时显示错误状态的上游缺陷，只允许在适配层做最小修补并记录原因，不得借修 bug 改造原运动设计。
- 内容正确：画面只出现原口播中的事实与获批素材，不自动创造金句、英文或概念。
- 移动端可读：横屏成片缩到 390px 宽复看；人物安全区、字幕、截图正文均可辨。
- 最终验收看真实 MP4，并检查入场、动作峰值、落定和边界连拍，不以静态截图或测试通过代替。
